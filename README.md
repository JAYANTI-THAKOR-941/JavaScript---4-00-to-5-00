# JavaScript and TypeScript Classroom Exercises

Numbered browser exercises covering variables, output, operators, calculators, forms, conditions and loops, with TypeScript examples.

## Project structure

- `01_JavaScriptAdd.html`
- `04_calculator.html`
- `10_loginForm.html`
- `12_typeScript.ts`
- `13_productManagement.html`
- `23_forLoop.html`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/JavaScript---4-00-to-5-00.git
cd JavaScript---4-00-to-5-00
```

Open HTML exercises in a browser. Use Node.js for standalone JavaScript files; compile TypeScript examples using an appropriate TypeScript compiler before execution.
